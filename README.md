Prime Talent Recrutamento & Seleção
Projeto Integrador de Infraestrutura Computacional

Este repositório contém a documentação técnica do projeto desenvolvido para as disciplinas de Arquitetura e Organização de Computadores, Sistemas Operacionais, Redes de Computadores e Internet das Coisas (IoT).

A empresa fictícia Prime Talent Recrutamento & Seleção foi criada para simular um ambiente corporativo real, permitindo o desenvolvimento de uma solução integrada de infraestrutura computacional.

Sobre a Empresa

A Prime Talent Recrutamento & Seleção atua no segmento de recrutamento e seleção de profissionais para empresas de diversos setores.

Solução IoT

O projeto IoT consiste em um monitor de temperatura da sala de servidores utilizando:

Arduino Uno R3
Sensor TMP36
LED Verde
LED Amarelo
LED Vermelho
Faixas de Operação
Temperatura abaixo de 28°C → LED Verde
Temperatura entre 28°C e 31,9°C → LED Amarelo
Temperatura igual ou superior a 32°C → LED Vermelho

Objetivo do Projeto

Desenvolver uma solução completa de infraestrutura computacional para uma empresa de recrutamento e seleção, integrando hardware, sistemas operacionais, redes corporativas e Internet das Coisas em um ambiente único, coerente e tecnicamente fundamentado.
